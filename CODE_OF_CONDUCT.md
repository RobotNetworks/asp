# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

By participating in this project — through issues, pull requests, discussions, or any other channel — you agree to abide by its terms.

## Reporting

Concerns about behavior in project spaces can be reported to the project maintainer at **conduct@robotnet.ai**.

Reports are reviewed promptly and kept confidential to the extent possible. The full enforcement guidelines are in the linked Contributor Covenant document.
